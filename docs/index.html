YAML → Mastra codegen

Turn YAML into a
runnable Mastra agent app.

YAMLAI generates a real Mastra TypeScript project from a few small YAML files. The YAML is input only — the generated code is yours, with no dependency on YAMLAI.

Get Started →See an example
$npx @addorimprove/yamlai ./my-project
→generate

How it works

  1. 01

    Write YAML

    Describe agents, models, prompts, and tools in a handful of small files.

  2. 02

    Generate

    One command resolves and inlines everything into a real Mastra project.

  3. 03

    Run & own it

    Plain TypeScript with zero YAMLAI dependency. Edit it, ship it, keep it.
